# ElevenSticks

**ElevenSticks** — это простая сетевая CLI-игра (Command Line Interface), в которой несколько игроков по очереди берут палочки из общей кучи.

По умолчанию:
- в куче **11 палочек**
- за ход можно взять **от 1 до 3**
- **игрок, взявший последнюю палочку, выигрывает**

Игра реализована на C++ с использованием POSIX-сокетов.

---

## Правила игры

1. В начале игры на столе лежит фиксированное количество палочек.
2. Игроки ходят по очереди.
3. За один ход игрок обязан взять количество палочек в допустимом диапазоне.
4. Игрок, взявший последнюю палочку, **выигрывает**.
5. В текущей версии поддерживается **только 2 игрока**.

---

## Обзор архитектуры

- **Client / Server модель**
- TCP-соединение
- Собственный бинарный протокол поверх TCP
- Сервер управляет логикой игры
- Клиенты получают состояние и отправляют ходы

Основные модули проекта:
- `server` — игровая логика и сетевой сервер
- `client` — клиентская часть
- `net_tools` — низкоуровневая работа с сетью
- `rules` — правила игры
- `logger` — логирование сервера.

## Процесс сборки

### Требования

- C++17 совместимый компилятор
- CMake
- POSIX-совместимая ОС (Linux, BSD, macOS)

### Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Процесс запуска

После сборки проекта исполняемый файл будет находиться по пути:

build/bin/eleven_sticks_run

### Запуск

./build/bin/eleven_sticks_run

При запуске программа предложит:
- запустить сервер или подключиться как клиент
- настроить правила игры (или использовать значения по умолчанию)
- ввести IP-адрес и порт сервера (в режиме клиента)


## Как играть

1. Один из игроков запускает сервер.
2. Второй игрок подключается к серверу, указав IP-адрес и порт.
3. Игроки по очереди убирают палочки из общей кучи.
4. За ход можно взять количество палочек в допустимом диапазоне.
5. Игра продолжается, пока палочки не закончатся.
6. Игрок, взявший последнюю палочку, побеждает.
7. После окончания игры оба клиента получают результат.


## Тестирование

После сборки проекта тесты (в настоящее время в разработке) как исполняемый файл будут находиться по пути:

build/bin/eleven_sticks_test


## Известные ограничения

- Поддерживается только 2 игрока
- Частичная защита от некорректных или злонамеренных клиентов
- Нет версионирования сетевого протокола
- Только интерфейс командной строки
- Поддерживаются только POSIX-платформы
