# ElevenSticks

**ElevenSticks** — это простая сетевая CLI-игра (Command Line Interface), в которой несколько игроков по очереди берут палочки из общей кучи.

По умолчанию:
- в куче **11 палочек**
- за ход можно взять **от 1 до 3**
- **игрок, взявший последнюю палочку, выигрывает**

Игра реализована на C++ с использованием POSIX-сокетов.

---

## Запуск
### Если собирали локально
После сборки проекта исполняемый файл будет находиться по пути build/bin/eleven_sticks_run.
Таким образом, нужно выполнить следующее - в корне проекта:
```bash
./build/bin/eleven_sticks_run
```
#### Если скачали из репозитория
В папке с файлом:
```bash
./eleven_sticks_run
```

## Как играть
При запуске программа предложит:
- запустить сервер или подключиться как клиент
- настроить правила игры (или использовать значения по умолчанию)
- ввести IP-адрес и порт сервера (в режиме клиента)

### Порядок действий
1. Один из игроков запускает сервер.
2. Он подключается к нему в режиме клиента, указав IP-адрес 127.0.0.1 и порт (в текущей версии 8080).
3. Второй игрок подключается к серверу, указав IP-адрес и порт.
4. В начале игры на столе лежит фиксированное количество палочек.
5. Игроки ходят по очереди.
6. За один ход игрок обязан взять количество палочек в допустимом диапазоне.
7. Игрок, взявший последнюю палочку, **выигрывает**.
8. После окончания игры оба клиента получают результат.

В текущей версии поддерживается **только 2 игрока**.

## Обзор архитектуры

- **Client / Server модель**
- TCP-соединение
- Собственный бинарный протокол поверх TCP
- Сервер управляет логикой игры
- Клиенты получают состояние и отправляют ходы

Основные модули проекта:
- `server` — игровая логика и сетевой сервер
- `client` — клиентская часть
- `net_tools` — низкоуровневая работа с сетью
- `rules` — правила игры
- `logger` — логирование сервера.

---

## Известные ограничения

- Поддерживается только 2 игрока
- Частичная защита от некорректных или злонамеренных клиентов
- Нет версионирования сетевого протокола
- Только интерфейс командной строки
- Поддерживаются только POSIX-платформы
